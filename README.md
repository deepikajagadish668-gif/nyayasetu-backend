\# NyayaSetu — AI-Powered Court Judgment Processing System



> Bridging Court Judgments to Government Action using AI — in every Indian language



\## 🌐 Live Demo

https://nyayasetu-backend-elpt.onrender.com



\## 🎯 Problem

\- 4.5 Crore+ pending cases in Indian courts

\- Months of delay in executing court orders

\- Language barriers across 22+ Indian languages



\## 💡 Solution

NyayaSetu reads court judgment PDFs, extracts action items using AI, and dispatches them to the right government departments instantly — in any Indian language.



\## ✨ Features

\- 📄 PDF upload \& AI text extraction

\- 🧾 Case summary in simple English

\- ⚖️ Verdict extraction \& classification

\- 📌 Key points in plain language

\- 🌐 Translation in 12 Indian languages

\- 💬 Chat with the judgment

\- ✅ Human verification before dispatch

\- 📊 Action tracking dashboard



\## 🛠️ Tech Stack

\- \*\*Frontend:\*\* HTML5, CSS3, Vanilla JS

\- \*\*Backend:\*\* Node.js, Express

\- \*\*AI:\*\* Groq API (LLaMA 3.3 70B)

\- \*\*PDF:\*\* pdf-parse

\- \*\*Deployment:\*\* Render + GitHub



\## 🚀 How to Run

1\. Clone the repo

2\. Run `npm install`

3\. Add `.env` file with `OPENAI\_API\_KEY=your\_groq\_key`

4\. Run `node server.js`

5\. Open `http://localhost:5000`
